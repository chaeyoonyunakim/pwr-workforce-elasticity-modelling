Curated write-ups of the analysis. The rendered headline report is at
[`../outputs/report.html`](../outputs/report.html) — that is the
canonical pipeline output, regenerated by
`python -m pwr_elasticity.pipeline`. Reports in this directory are
narrative companions to that artefact.

## How to view the rendered report

GitHub does not render HTML inline. Three viewing paths:

1. **Local clone:** open `outputs/report.html` directly in a browser.
2. **Raw download** from the GitHub UI by clicking the file then
   "Download raw file".
3. **HTML preview services:** paste the raw URL into
   [htmlpreview.github.io](https://htmlpreview.github.io/) — e.g.
   `https://htmlpreview.github.io/?https://github.com/chaeyoonyunakim/pwr-workforce-elasticity-modelling/blob/main/outputs/report.html`.

## Regenerating

```bash
pip install -e ".[dev]"
python -m pwr_elasticity.pipeline
```

`outputs/report.html` and the supporting parquet artefacts are
rewritten in place. `outputs/manifest.json` records the source-file
SHA-256 hashes, package versions, git commit and seed used.

## Caveats preserved across runs

- **TAC coverage.** The panel covers NHS trusts only (66–68 providers
  × 4 years = 263 rows). Foundation Trust accounts are published as a
  separate TAC dataset that is not currently loaded. Adding it would
  extend the panel to ~213 providers. The TAC reader supports older
  vintages back to at least 2019/20 via a SubCode candidate list — see
  `evaluation.md` for details.
- **Identification.** Pre-trend diagnostic rejects strict parallel
  trends; the placebo p-value is ~0.29 on the four-FY permutation set.
  Headline coefficient is therefore reported as a *policy-period
  descriptive elasticity*, not a clean causal effect.
- **Bank vs Agency.** TAC does not separate Bank from Agency; the
  outcome variable is the combined "Other staff" line. The
  bank-versus-agency cost-inversion story is supported separately by
  the REC FOI extracts documented in
  [`../data/DATA_DICTIONARY.md`](../data/DATA_DICTIONARY.md) §3.9.
