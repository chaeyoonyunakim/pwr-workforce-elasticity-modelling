# Reports

Versioned snapshots of the headline analysis. Generated by
[`pwr_elasticity.report.build_report`](../src/pwr_elasticity/report.py)
and committed here so they can be linked to from issues, PRs and
external write-ups without re-running the pipeline.

Snapshots are **not** the source of truth. The canonical, reproducible
output is whatever `python -m pwr_elasticity.pipeline` produces from
the current `data/` and `src/` against the committed
`pyproject.toml`. To regenerate locally:

```
pip install -e ".[dev]"
python -m pwr_elasticity.pipeline
```

Then open `outputs/report.html`. The pipeline also writes
`outputs/manifest.json` recording the source-file SHA-256 hashes,
package versions, git commit and seed used.

## How to view

GitHub does not render HTML inline. Two practical viewing paths:

1. **Local clone:** `open reports/report.html` (macOS) /
   `start reports\report.html` (Windows) / `xdg-open reports/report.html`
   (Linux).
2. **GitHub Pages:** if `reports/` is published as a Pages source,
   the report is served directly at
   `https://chaeyoonyunakim.github.io/pwr-workforce-elasticity-modelling/report.html`.
   This is not enabled by default.

## Important caveats

- **TAC coverage.** The panel covers NHS trusts only; Foundation
  Trust accounts are published as a separate TAC dataset that is not
  currently loaded. Adding it would extend the panel to ~213
  providers.
- **Identification.** The pre-trend diagnostic rejects strict
  parallel trends and the placebo p-value is ~0.29 on the four-FY
  permutation set. The headline coefficient is therefore reported as
  a *policy-period descriptive elasticity*, not a clean causal
  effect.
- **Bank vs Agency.** TAC does not separate Bank from Agency; the
  outcome variable is the combined "Other staff" line. The
  bank-versus-agency cost-inversion story is supported separately by
  the REC FOI extracts documented in
  [`../data/DATA_DICTIONARY.md`](../data/DATA_DICTIONARY.md) §3.9.
